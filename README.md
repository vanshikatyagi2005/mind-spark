# Mind Spark

Mind Spark is a learning web application built using Django.

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS

## Project Pages
- Home
- Quiz
- Quiz Results
- Quiz History
- Leaderboard
- Topic Details

## How to Run
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install Django.
4. Set the `DJANGO_SECRET_KEY` environment variable.
5. Run database migrations using `python manage.py migrate`.
6. Start the server using `python manage.py runserver`.
